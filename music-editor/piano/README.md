# Piano samples

Salamander Grand Piano V3 by Alexander Holm, licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
Taken from the `@audio-samples/piano-mp3-velocity8` npm package (MIT, see
`LICENSE-samples.txt`), then trimmed to 6 seconds with a fade-out and
converted to mono MP3 to keep downloads small.

One sample every three semitones from A0 to C8 (`Ds` = D#, `Fs` = F#).
The player pitch-shifts the nearest sample for all other notes.
